## Themes

Switch with `Super+Shift+T`. **Glass** and **BlackArch** are *generated* by [`themeforge`](themeforge/README.md)
from one token file each (every layer: Hyprland, Waybar, Rofi, kitty, tmux, GTK3/4, Qt/Kvantum, lockscreen,
Neovim, VS Code); the four older themes below are hand-written.

| Theme | Palette | Vibe |
|---|---|---|
| **Glass** | translucent · accent `#0A84FF` | liquid glass — blur, rim light, squircle corners |
| **BlackArch** | `#000000` · Arch blue `#1793D1` | flat true-black, zero effects |

## Install

### Prerequisites

1. Arch Linux
2. HyDE installed → https://github.com/HyDE-Project/HyDE
3. Packages: `zsh oh-my-zsh-git starship tmux kitty btop fastfetch eza zoxide fzf bat fd ripgrep lazygit lazydocker`

### Clone and run

```bash
git clone https://github.com/Imad-Oute/dotfiles ~/dotfiles
cd ~/dotfiles
chmod +x install.sh
./install.sh
```

The script symlinks everything into place and backs up any existing files to `~/.dotfiles-backup-<timestamp>`.

`install.sh` also runs `themeforge/forge.py install all`, which **rebuilds Glass + BlackArch from scratch**
(needs `python3 >= 3.11`, `imagemagick`; optional `code` for the VS Code themes). Then, **once per machine**:

```bash
# HyDE only uses a theme's own colours in wallbash "theme" mode (0). Other modes use the wallpaper.
sed -i 's/^enableWallDcol=.*/enableWallDcol="0"/' ~/.local/state/hyde/staterc
```

Update flow on any machine: `git pull && ./install.sh` (idempotent; backs up anything it replaces).
Tweak a colour/radius/blur: edit `themeforge/tokens/<theme>.toml`, run `python3 themeforge/forge.py install all`.

### Wallpapers

Glass / BlackArch wallpapers are **generated** (ImageMagick, `themeforge/wallpapers.sh`). For the other themes,
wallpapers are not in the repo — see [wallpapers.md](wallpapers.md) for Wallhaven IDs.

### Tmux plugins

After install, open tmux and press `prefix + I` (that's `Ctrl+Space + I`) to install TPM plugins.

## What's tracked

```
dotfiles/
├── .config/
│   ├── hypr/              Hyprland — userprefs, keybindings, windowrules, animations...
│   ├── hyde/
│   │   ├── config.toml    HyDE behavior
│   │   ├── themes/        Claude Dark · Neural · Phantom · Entropy (hand-written)
│   │   └── wallbash/always/  firefox.dcol · themeforge-nvim.dcol (palette export for Neovim)
│   ├── waybar/            user-style.css overrides
│   ├── kitty/             kitty.conf base config
│   ├── nvim/              Neovim / LazyVim config (+ colors/glass.lua, lua/themeforge/)
│   ├── starship/          starship.toml prompt
│   ├── btop/              btop.conf
│   ├── fastfetch/         fastfetch config + logo
│   └── dunst/             notification config
├── themeforge/           theme generator: tokens/*.toml → every layer (see its README)
└── home/
    ├── .zshrc             shell aliases, PATH, tool init
    └── .tmux.conf         tmux + TPM config
```

## What's NOT tracked

- `~/.config/hypr/themes/` — auto-generated by HyDE on every theme/wallpaper switch
- `~/.config/waybar/config.jsonc`, `style.css` — auto-generated by wbarconfgen
- `~/.config/kitty/theme.conf` — auto-generated by HyDE theme switcher
- `~/.zshrc.local` — machine-local secrets (API keys etc.)
- Wallpaper images — see [wallpapers.md](wallpapers.md)
- `themeforge/build/` — generated output (rebuilt by `install.sh`); also generated and gitignored:
  `.config/hypr/hyprlock/{Glass,BlackArch}.conf`, `.config/hypr/monitors.lua`, `workspaces.lua`

### Where the generated Glass / BlackArch pieces end up (on every machine)

| What | Path |
|---|---|
| HyDE theme dirs (real copies) | `~/.config/hyde/themes/{Glass,BlackArch}/` |
| GTK 3/4 themes | `~/.local/share/themes/{Glass,BlackArch}/` |
| Qt / Kvantum | inside the theme dir (`kvantum/`), deployed by HyDE to `~/.config/Kvantum/wallbash/` |
| Rofi launcher style | `~/.local/share/rofi/themes/glass.rasi` |
| Lockscreen layouts | `~/.config/hypr/hyprlock/{Glass,BlackArch}.conf` |
| VS Code themes | extensions `themeforge.themeforge-{glass,blackarch}` |
| Neovim | `~/.config/nvim/colors/glass.lua` + `lua/themeforge/` (tracked, linked) |
| VS Code theme switch hook | `~/.local/lib/themeforge/vscode-theme.py` |
